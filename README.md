# flu-forecast-runner

Weekly submissions of the DMA-PRIME models DMAPRIME-HYB (CDC FluSight) and DMAPRIME-ObsHYB
(Flu MetroCast). The models, their documentation and the code to run them locally are in
[DMA-PRIME/FluSight-HYB](https://github.com/DMA-PRIME/FluSight-HYB).
